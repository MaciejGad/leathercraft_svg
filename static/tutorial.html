Learn to write .lcraft by building real patterns in your browser

This tutorial starts with tiny examples and gradually moves toward more useful leatherworking patterns. Every sample on this page is editable, so you can change the code, render it again, and see exactly what the DSL produces.

loading browser compiler Open full browser editor

1. Start simple

Begin with a pattern name, a page size, and one shape. That is enough to generate a useful SVG.

2. Add structure

Once the outline exists, add holes, stitch marks, and guide lines block by block.

3. Tweak by eye

Use the live samples to adjust spacing, radii, and panel sizes until the design feels right.

Interactive walkthrough

Work through these examples in order. Each one introduces one new idea, while keeping the rest of the file easy to read. A good learning rhythm is: render the sample once, change one value, then render again and compare the result.

What to try next

Once you are comfortable with these building blocks, move into the full editor and experiment with:

  • different shape types such as ellipses, stadiums, and rounded polygons,
  • changing layers between cut, stitch, crease, and guide,
  • adjusting hole spacing and stitch angles for your material and machine,
  • turning one working panel into a larger project with matching companion pieces.
